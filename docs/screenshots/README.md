## 💡 Dicas para Capturas com Máxima Qualidade
1. Pressione **F1** no jogo para ocultar a barra de vida, mira e HUD para fotos limpas e cinematográficas.
2. Pressione **F2** para tirar o print nativo do Minecraft (fica salvo em `.minecraft/screenshots` ou na pasta `run/screenshots/`).
3. Basta copiar a imagem capturada para cá: `docs/screenshots/<nome_desejado>.png`.
4. Avise no chat quando terminar de colar as imagens para que elas sejam automaticamente inseridas com links no `README.md`!
