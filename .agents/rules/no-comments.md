# No Comments in Code

Never add comments to source code files. This applies to all languages (Java, Kotlin, JavaScript, Python, etc.) and all comment styles (`//`, `/* */`, `#`, `--`, `<!-- -->`).

Do not add:
- Inline comments explaining what a line does
- Block comments describing logic
- Section separators or labels
- TODO / FIXME / NOTE annotations
- Any other form of code comment

Write self-documenting code using clear method and variable names instead.
